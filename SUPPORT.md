# Support | 支持

## Getting Help | 获取帮助

For project usage, build, test, or repository questions, start with:
关于项目使用、构建、测试或仓库问题，建议先看：

- [README.md](README.md)
- [docs/README.md](docs/README.md)
- [docs/BUILD.md](docs/BUILD.md)
- [docs/TESTING.md](docs/TESTING.md)
- [docs/BINDINGS.md](docs/BINDINGS.md)

## When to Open an Issue | 何时提交 Issue

Open an issue if you have:
以下情况建议提交 issue：

- a reproducible bug / 可复现 bug
- a build failure with environment details / 带环境信息的构建失败
- a documentation error tied to the current source tree / 与当前源码树不一致的文档错误
- a test failure that can be reproduced / 可复现的测试失败

## What to Include | 建议附带的信息

Please include as much of the following as possible:
请尽量附带以下信息：

- operating system and toolchain / 操作系统与工具链
- build commands used / 使用的构建命令
- relevant logs or error output / 相关日志或报错输出
- minimal reproduction steps / 最小复现步骤
- affected module or example / 受影响模块或示例

## Expectations | 预期

Current support is best-effort only.
当前支持方式仅为 best-effort。

MBlink is primarily maintained as a personal project.
MBlink 目前主要还是一个个人维护项目。

Because development time and testing capacity are limited, not every example, platform, binding, framework combination, or edge case can be verified one by one before release.
由于个人开发时间和测试精力有限，不可能在发布前把每个示例、每个平台、每种绑定、每个框架组合和所有边角情况都一一测试完。

The repository does not currently document:
当前仓库未提供：

- formal support windows / 正式支持周期
- guaranteed response times / 保证响应时间
- commercial support channels / 商业支持渠道
