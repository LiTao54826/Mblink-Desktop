# Code of Conduct | 行为准则

## Our Standard | 基本准则

Please keep collaboration respectful, clear, and technical.
请保持协作过程尊重、清晰、聚焦技术。

Expected behavior includes:
期望行为包括：

- discussing code, behavior, and evidence rather than personal attacks
  讨论代码、行为和证据，而不是人身攻击
- providing reproducible reports when possible
  尽量提供可复现报告
- keeping review comments specific and actionable
  让 review 评论具体且可执行
- respecting different experience levels and backgrounds
  尊重不同经验水平和背景

Unacceptable behavior includes:
不可接受的行为包括：

- harassment or abusive language / 骚扰或辱骂性语言
- repeated personal attacks / 重复人身攻击
- intentionally misleading technical discussion / 故意误导性的技术讨论
- publishing private or sensitive information without permission / 未经许可公开私人或敏感信息

## Scope | 适用范围

This applies to repository discussions, issues, pull requests, and other project communication spaces.
本准则适用于仓库讨论、issues、pull requests 及其他项目沟通场景。

## Enforcement | 执行

Project maintainers may remove, edit, or reject contributions and interactions that violate these standards.
项目维护者可移除、编辑或拒绝违反本准则的贡献与互动。

## Notes | 说明

This document is intentionally lightweight and repository-focused.
本文档刻意保持轻量，并聚焦于仓库协作本身。
