# 样式测试说明

`tests/style_tests/` 包含一组用于观察样式系统和布局行为的测试脚本与对比页面。

## 用途

这部分内容更适合视为：
- 手工验证脚本
- 浏览器对比素材
- 样式 / 布局问题复现样例

而不是“已经稳定维护并自动验证通过”的正式测试套件说明。

## 当前目录中可观察的内容

通常包括：
- `.js` 测试脚本
- 对应的 `.html` 对比页面
- 本地启动脚本
- 批量运行脚本

## 建议使用方式

如果需要验证某个样式问题：

1. 先在浏览器中打开对应 HTML 页面观察标准效果
2. 再使用 `esm_loader` 运行对应 JS 脚本
3. 比较布局、滚动、文本、颜色与交互差异

## 当前不应过度承诺的内容

目前不应直接写成：
- 所有样式测试都已自动化
- 所有场景都与浏览器一致
- 所有脚本在当前版本都已验证通过

更准确的表述是：这是一组用于样式行为检查和回归观察的辅助测试材料。
