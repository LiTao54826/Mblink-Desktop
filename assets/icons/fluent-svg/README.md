# Fluent UI System Icons (SVG) | Fluent 图标

## Overview | 概览

Common icons extracted from Microsoft Fluent UI System Icons.
从 Microsoft Fluent UI System Icons 提取的常用图标资源。

## How to Obtain Icons | 获取方式

Automatic download is not guaranteed in the current repository workflow.
当前仓库流程不保证自动下载成功，必要时请手动准备。

### SVG Icons | SVG 图标

1. Visit https://github.com/microsoft/fluentui-system-icons
   访问 https://github.com/microsoft/fluentui-system-icons
2. Download the required assets
   下载所需图标资源
3. Place them in this directory
   放入当前目录

### Font Files | 字体文件

1. Visit https://github.com/nicholasrice/fluentui-system-icons-font/releases
   访问字体发布页
2. Download `FluentSystemIcons-Regular.ttf` and `FluentSystemIcons-Filled.ttf`
   下载所需字体文件
3. Place them in `assets/fonts/`
   放入 `assets/fonts/`
