# Fluent UI System Icons (SVG)

从 Microsoft Fluent UI System Icons 提取的常用图标。

## 下载完整图标

由于网络原因无法自动下载，请手动下载：

### SVG 图标
1. 访问 https://github.com/microsoft/fluentui-system-icons
2. 下载 `assets` 目录下需要的图标
3. 放到此目录

### 字体文件
1. 访问 https://github.com/nicholasrice/fluentui-system-icons-font/releases
2. 下载 `FluentSystemIcons-Regular.ttf` 和 `FluentSystemIcons-Filled.ttf`
3. 放到 `assets/fonts/` 目录
