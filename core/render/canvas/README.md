# Canvas Rendering

HTML5 Canvas 2D 渲染上下文实现。

## 模块列表

| 文件 | 描述 |
|------|------|
| `canvas_rendering_context_2d.h/cpp` | CanvasRenderingContext2D 实现 |
| `canvas_path.h/cpp` | 路径操作 |
| `canvas_gradient.h/cpp` | 渐变实现 |
| `canvas_pattern.h/cpp` | 图案填充 |

## 功能说明

实现 HTML5 Canvas 2D API：
- 路径绑制（moveTo, lineTo, arc, bezierCurveTo 等）
- 填充和描边
- 变换（translate, rotate, scale）
- 图像绘制
- 文本绘制
- 渐变和图案
