# DevTools Inspector

元素检查器模块，提供 DOM 元素选择和检查功能。

## 模块列表

| 文件 | 描述 |
|------|------|
| `element_picker.h/cpp` | 元素选择器，支持鼠标悬停高亮和点击选择 |
| `element_tree.h/cpp` | DOM 树视图渲染 |
| `box_model.h/cpp` | Box Model 可视化 |
| `computed_styles.h/cpp` | 计算样式显示 |

## 功能说明

- 元素选择：鼠标悬停高亮，点击选中
- DOM 树导航：展开/折叠节点
- Box Model：显示 margin/border/padding/content
- 计算样式：显示元素的最终样式值
