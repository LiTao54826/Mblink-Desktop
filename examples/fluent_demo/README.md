# Fluent Design 组件演示

这是 MBink Fluent Design 组件库的演示应用。

## 运行方式

在 MBink 中加载 `index.html` 或直接运行 `app.js`。

## 演示内容

- **Buttons** - 按钮组件（外观、尺寸、形状、状态）
- **Input Components** - 输入组件（Input、SearchBox、Textarea、Select、Checkbox、Switch、Radio）
- **Data Display** - 数据展示（Typography、Badge、Avatar、Divider）
- **Cards** - 卡片组件
- **Feedback** - 反馈组件（Spinner、Link）

## 截图

组件库完全遵循 Microsoft Fluent UI 设计规范，提供一致的视觉体验。
