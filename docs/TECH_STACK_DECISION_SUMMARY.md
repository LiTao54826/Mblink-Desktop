# 技术选型决策总结

## 📋 执行摘要

**日期**: 2025-11-11  
**决策**: 保持当前核心技术栈，新增 stb_image 和 Lexbor 两个轻量级库  
**影响**: 节省 2-3 周开发时间，提升代码质量

---

## 🎯 决策背景

在完成 Phase 2.4 后，准备开始 Phase 2.5（JavaScript 基础设施完善）时，我们重新审视了整个项目的技术选型，确保：
1. 当前技术栈是否最优
2. 是否有成熟的第三方库可以减少重复造轮子
3. 如何在轻量级和功能完整性之间取得平衡

---

## ✅ 核心技术栈决策

### 保持不变的核心依赖

| 库名 | 用途 | 决策 | 理由 |
|------|------|------|------|
| **QuickJS-ng** | JavaScript 引擎 | ✅ 保持 | 体积最小（600KB），完整 ES6+ 支持，易于嵌入 |
| **Skia** | 2D 渲染引擎 | ✅ 保持 | Chrome/Flutter 使用，行业标准，功能最完整 |
| **SDL3** | 窗口/事件系统 | ✅ 保持 | 最新版本，跨平台首选，内置 IME 支持 |
| **Yoga** | Flexbox 布局 | ✅ 保持 | React Native 同款，与 React 生态完美契合 |
| **nlohmann/json** | JSON 解析 | ✅ 保持 | C++ 最佳 JSON 库，单头文件 |
| **GoogleTest** | 单元测试 | ✅ 保持 | 行业标准测试框架 |

**总体评价**: ⭐⭐⭐⭐⭐ 优秀
- 所有选择都是各自领域的最佳或次佳方案
- 体积控制在 10-15MB，符合轻量级目标
- 无依赖冲突，跨平台支持完善

---

## 🆕 新增依赖决策

### 1. stb_image - 图片加载库

**决策**: ✅ **立即集成**

**理由**:
- ✅ 单头文件库，零依赖
- ✅ 体积极小（~10KB）
- ✅ 被 Unity, Unreal, Godot 等广泛使用
- ✅ 支持 PNG/JPG/BMP/GIF/PSD/TGA 等所有常见格式
- ✅ 5 分钟即可集成

**替代方案对比**:
- ❌ Skia 内置解码器 - 需要额外配置，不够灵活
- ❌ libpng + libjpeg - 需要多个库，体积大（5MB+）
- ❌ 自己实现 - 工作量巨大，容易有 bug

**影响**:
- Phase 2.5 Task 7.1（`<img>` 元素）可以快速完成
- 节省 1-2 天开发时间

---

### 2. Lexbor - HTML/CSS 解析器

**决策**: ✅ **立即集成**

**理由**:
- ✅ 纯 C 语言，超高性能
- ✅ 完整的 HTML5 + CSS3 支持
- ✅ 零依赖
- ✅ 完整的 CSS 选择器引擎（querySelector, querySelectorAll）
- ✅ 被 Servo、Chromium 等项目参考
- ✅ 活跃维护，文档完善

**替代方案对比**:
- ❌ 自己实现 CSS 选择器 - 需要 2-3 周，容易有 bug
- ⚠️ gumbo-parser - 只支持 HTML，不支持 CSS
- ⚠️ pugixml - 只支持 XML，不支持 HTML5

**影响**:
- Phase 2.5 Task 3（querySelector）可以快速完成
- Phase 2.5 Task 8（CSS 解析）可以快速完成
- 节省 2-3 周开发时间
- 代码质量更高（使用成熟库）

---

## ❌ 不集成的库

### 1. libuv - 异步 I/O

**决策**: ❌ **不集成**

**理由**:
- 我们已经有 EventLoop 实现
- libuv 会增加复杂度
- 当前不需要异步文件 I/O

---

### 2. WebView - 嵌入浏览器

**决策**: ❌ **不集成**

**理由**:
- 与项目目标冲突（我们要替代浏览器，不是嵌入浏览器）
- 体积大，依赖系统浏览器

---

### 3. V8 / JavaScriptCore - 其他 JS 引擎

**决策**: ❌ **不替换 QuickJS**

**理由**:
- V8 体积太大（50MB+），违背轻量级目标
- JavaScriptCore 体积中等（10MB+），但嵌入难度高
- QuickJS-ng 性能足够，体积最小

---

## 📊 技术栈对比

### 与竞品对比

| 特性 | LightUI | Electron | Tauri | Qt |
|------|---------|----------|-------|-----|
| **总体积** | 10-15MB | 100MB+ | 20MB+ | 30MB+ |
| **JS 引擎** | QuickJS (600KB) | V8 (50MB) | V8 (50MB) | QJSEngine (小) |
| **渲染引擎** | Skia (8MB) | Chromium (50MB) | WebView (系统) | Qt Widgets |
| **布局引擎** | Yoga (200KB) | Blink | WebView | Qt Layout |
| **窗口系统** | SDL3 (2MB) | Chromium | Tao | Qt |
| **React 支持** | ✅ 原生 | ✅ 完整 | ✅ 完整 | ❌ |
| **跨语言** | ✅ 多语言 | ⚠️ JS only | ⚠️ Rust only | ✅ C++ |

**结论**: LightUI 在体积和跨语言支持上有明显优势
